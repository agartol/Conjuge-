# Conjugue !

Aplicación para practicar la conjugación francesa de cara al DELF B1: conjugador, tarjetas con repetición espaciada, verbos irregulares, dictado, textos con huecos, transformaciones, hipótesis con *si*, trampas y examen.

Web: https://agartol.github.io/Conjuge-/

El progreso se guarda en el navegador de cada dispositivo. Las funciones de corrección con Claude solo están disponibles en la versión publicada dentro de Claude.
